キー操作

0–9

x / \ ~ b
ミュート・スライド・ビブラート・チョーキング
h p
ハンマリング／プリングの記号を上に付ける（行き先の音で押す。もう一度で消える）
r
休符（長さは次の音までで自動。もう一度で消える）
c
コード入力（Am7、G、C/E など）。押さえ方を縦1列に入れて次へ進む。c→Enter で同じコードをもう一度
t
タイ：選んだ音から同じ弦の次の音へ弧を付ける（次の音は弾き直さない）。もう一度で外す
⇧+Delete
縦1列（コードごと）消す
←→↑↓
1マス・1弦ずつ移動
Space
設定した音価ぶん進む（⇧で戻る）
Tab
次の小節へ（⇧で前へ）
Delete ⌫
消す
Enter
再生 / 停止
⌘Z ⇧⌘Z
元に戻す / やり直す
⇧+矢印・⇧+クリック・ドラッグ
範囲を選ぶ（小節をまたいでOK）。Esc で解除
⌘C ⌘X ⌘V
範囲のコピー / 切り取り / 貼り付け（範囲なしなら小節ごと）。貼り付けはクリックした位置から。複数の弦は同じ弦へ、1本だけならクリックした弦へ入る。Delete で範囲を消す
⌥+←→
選んだ範囲（なければ今のマス）を1マス移動。⇧も押すとスペースの幅で移動
⌥+↑↓
隣の弦へ移す（フレットの数字はそのまま）。⇧も押すと同じ音になるようフレットを付け替える
範囲をドラッグ

⌘D
