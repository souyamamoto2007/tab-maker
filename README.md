# TABメーカー

ベース・ギターのTAB譜をキーボードで打ち込み、A4のPDFにできるブラウザ用エディタです。インストール不要で、`index.html` を開くだけで動きます。

## できること

- 数字キーでフレット入力（12 などは続けて打つ）、矢印・スペースで移動
- 4弦・5弦ベース、ギター（ドロップD・半音下げ）、カポ
- 小節ごとの拍子（4/4、3/4、6/8 など）、線譜の中に拍子記号
- 線譜の下にリズム（符尾・連桁・付点）を自動で描画、タイ、休符
- ハンマリング／プリングの記号、スライド・ビブラートなど
- コード名を打つと押さえ方を自動で入力（チューニング・カポに対応）
- 範囲選択でコピー・切り取り・貼り付け・移動
- 再生して耳で確認
- 印刷画面から A4 の PDF に保存、譜面ファイル（.json）の書き出し・読み込み

譜面は使っているブラウザに自動保存されます。サーバーには送られません。

キー操作の一覧は画面右側の「キー操作」にあります。
